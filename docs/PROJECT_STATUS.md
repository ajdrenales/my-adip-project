## Verification fixes applied (uncommitted)
- `frontend/tsconfig.node.json`: added `composite: true`, replaced `noEmit` with
  `declaration` + `emitDeclarationOnly` plus an `outDir` under
  `node_modules/.tmp`, and limited `include` to `vite.config.ts`. Before this,
  `tsc -b` failed with TS6306/TS6310 and `npm run build` produced no `dist/`.
- `frontend/tsconfig.json`: added `tsBuildInfoFile` under `node_modules/.tmp` so
  `tsc -b` no longer writes a `.tsbuildinfo` file into the repository.
- Prettier formatting applied (`npm run format`): 19 frontend files gained a
  missing final newline; `index.html` and `src/App.tsx` were reflowed to the
  configured `printWidth: 100`.
- `.gitignore`: added `*.tsbuildinfo`.
- `frontend/package-lock.json` is now generated by `npm install` and should be
  committed with the rest of Milestone 0.

## Known issues
- Docker Desktop is not installed in the Linux development container, so
  `docker compose up --build`, the PostgreSQL container, and the PowerShell
  `Invoke-RestMethod http://localhost:8000/health` check have **not** been
  verified. These must still be run on the Windows ThinkPad L380.
- `frontend/package.json` declares `vite ^6.0.5` together with `vitest ^2.1.8`.
  Vitest 2.x requires Vite 5, so npm installs a second, nested `vite@5.4.21`
  under `node_modules/vitest/`. This is development-only tooling, but it caused
  the `tsc -b` type conflict now worked around above and it produces 5 npm audit
  advisories (3 moderate, 1 high, 1 critical). `npm audit` reports the only
  remedy as a breaking dev-dependency bump (`vitest@5.0.3`); that upgrade was
  deliberately not applied in Milestone 0 to keep the change minimal and is
  recommended as a separate, individually verified task.
- `vitest.config.ts` is no longer typechecked by `tsc -b` (typechecking it
  requires a single Vite version). It is still linted by ESLint and executed by
  Vitest, which passes.
- pytest prints a third-party deprecation warning from `starlette`/`anyio`
  (`anyio.abc.BlockingPortal` alias). Harmless; upgrade when convenient.
